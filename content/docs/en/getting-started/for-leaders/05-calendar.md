# Step 5: Setting Up the Calendar

> This page has been generated by AI and may contain severe factual inaccuracies or mistakes.
> Use at your own risk.

Your club's calendar is the central hub that keeps everyone synchronized. It tells members when to show up, what they'll be doing, and where they need to be. When combined with the absence reporting system, the calendar becomes even more powerful—members report absences for specific calendar events, and leaders can see at a glance how many people will be present for each activity.

Setting up an effective calendar requires more than just adding dates. You need to think about how your schedule works, what information members need, and how to keep the calendar maintained as your season or semester progresses.

## Understanding Calendar Events

Every entry on your club's calendar is an event. Events represent any scheduled activity where members might need to attend: practices, rehearsals, performances, competitions, meetings, social gatherings, or any other planned activity.

Each event contains several pieces of information that help members understand what's happening:

**Title** - A clear, concise name for the event. This should be instantly recognizable to members. Examples: "Tuesday Practice", "Regional Competition", "Spring Performance", "Officers Meeting".

**Date and Time** - When the event occurs, including both start and end times. Accurate timing helps members plan their schedules and know how long they'll be occupied.

**Location** (optional but recommended) - Where members should go. This is especially important if your club uses multiple venues or if locations vary by event type. Examples: "Band Room 201", "Main Stage", "Away at Jefferson High School", "Virtual (Zoom link in files)".

**Description** (optional) - Additional details that don't fit in the title. Use this for special instructions, things to bring, dress code, or anything else members should know in advance.

The calendar doesn't just display this information—it also connects to the absence reporting system. When members submit absence reports, they select which calendar event they'll miss. This connection allows leaders to see attendance expectations before events happen.

## Planning Your Calendar Structure

Before adding individual events, think about your club's scheduling patterns. Most clubs fall into one of several common patterns that should inform how you structure your calendar.

### Regular Recurring Events

Many clubs have predictable, repeating schedules. Examples include:

- Sports teams with daily or weekly practices
- Music ensembles with standard rehearsal times
- Clubs with regular meeting schedules

For recurring events, you'll need to add each occurrence individually (current tools don't support automatic recurrence), but using consistent naming and timing makes this faster and helps members recognize the pattern.

**Naming Strategy for Recurring Events:**

- Use day names: "Monday Practice", "Wednesday Rehearsal"
- Or use week numbers: "Practice - Week 1", "Practice - Week 2"
- Keep timing and location consistent when possible

### Variable Schedules

Some clubs don't have regular patterns—every event is unique. Theater productions, for example, might have irregular rehearsals based on which scenes are being worked on, different call times for different cast members, and varying locations.

For variable schedules:

- Be extra clear in event titles about what's happening
- Use descriptions liberally to explain expectations
- Consider adding location even for "home" events to clarify rooms or spaces
- Update calendar as early as possible when plans change

### Seasonal or Tiered Schedules

Many clubs have different schedule patterns depending on the time of year or stage of activity. A robotics team might have weekly meetings in the fall but daily builds in the winter. A theater might have read-throughs, rehearsals, tech week, and performance week, each with different schedules.

For seasonal schedules:

- Use event titles that indicate the phase: "Tech Rehearsal", "Build Season - Day 3"
- Group related events with consistent naming
- Add a season-start event with information about the upcoming schedule
- Consider creating different calendar "periods" in your planning

## Creating Your First Events

Let's walk through adding events to your calendar. Start with your most important or immediate events—you don't need to populate an entire semester at once.

### Accessing the Calendar

From your club homepage, click **Calendar** in the sidebar. You'll see a monthly view by default, though you can switch to week or day views depending on your preference.

### Adding an Event

1. **Click on a Date** - Click the date when you want to add an event. If you're adding a multi-day event, start with the first day—you'll specify the date range in a moment.

2. **Fill in Event Details:**

   **Event Title** - Enter a clear, descriptive name. Think about how it will appear in the monthly view where space is limited. Good titles are brief but informative.

   Examples of good titles:
   - "Practice - Conditioning Focus"
   - "Spring Concert"
   - "Officers Meeting"
   - "Away Game @ Lincoln HS"

   Examples of poor titles:
   - "Event" (too vague)
   - "Practice Session for Marching Band Members Who Need Extra Help with the Third Movement" (too long)
   - "Mtg" (unclear abbreviation)

   **Start Time and End Time** - Set when the event begins and ends. Be realistic about timing—if practice usually runs long, account for that in the end time so members plan appropriately.

   Consider:
   - Include setup/teardown time if relevant
   - Account for travel time for away events
   - Be consistent with typical durations so members can spot anomalies

   **Location** - Add where members should go. Even for regular venues, including location helps new members and reminds everyone if there are multiple possible locations.

   Format examples:
   - "Room 215, Arts Building"
   - "Main Gymnasium"
   - "Virtual (check Discord for link)"
   - "Away - 123 Main St, Springfield"

   **Description** (optional) - Use this for any additional details members should know:
   - "Bring your music folder and water bottle"
   - "Dress rehearsal - full costume required"
   - "Optional conditioning session"
   - "Parents invited to attend"

3. **Save the Event** - Click Create or Save. The event appears on the calendar immediately and all members with calendar viewing permissions can see it.

### Adding Multiple Events Efficiently

If you need to add many events (like a whole season of practices), work smart:

**Batch Planning** - Plan all your events in a spreadsheet first, then add them to the calendar in one session. This helps you spot conflicts and maintain consistency.

**Copy and Adjust** - If you can duplicate events in the system (some implementations allow this), use it. Create a template event with standard settings, duplicate it, then adjust the date and any unique details.

**Weekly Blocks** - Add one week at a time rather than the entire semester. This gives you flexibility to adjust as needs change without having to update dozens of future events.

## Calendar Best Practices

Maintaining an effective calendar is an ongoing responsibility. These practices help keep your calendar useful and trustworthy.

### Update Proactively

When changes happen, update the calendar immediately. Don't wait until the day before or assume you'll remember to mention it at the event. Members rely on the calendar for planning, and outdated information erodes trust.

**What to update:**

- Cancellations (remove or mark as cancelled)
- Time changes (edit start/end times)
- Location changes (especially important!)
- Event type changes ("Practice" becomes "Performance Review")

### Add Events in Advance

Members need time to plan their lives around club activities. Add events to the calendar as soon as you know about them, ideally:

- Regular events: at least one week ahead
- Special events: at least two weeks ahead
- Major events (performances, competitions): at least one month ahead

The more advance notice you give, the fewer last-minute absences you'll face.

### Use Consistent Naming

Patterns help members quickly scan the calendar and understand what's happening. If you call Monday's activity "Practice", don't suddenly switch to "Rehearsal" or "Training" unless the nature of the activity actually changed.

**Create a naming convention and stick to it:**

- Practice vs. Rehearsal (pick one)
- Meeting vs. Gathering vs. Session (pick one)
- Performance vs. Show vs. Concert (pick one or use context-appropriate terms)

### Include All Relevant Activities

Add everything members need to know about, not just mandatory events. Consider adding:

- Optional activities (marked clearly as optional)
- Officer meetings (even though not everyone attends)
- Important deadlines ("Dues Payment Due" as an all-day event)
- Related events (school pep rallies if the band performs, opponent game days for sports support)

Members can then see the full picture of club life, even if they're not required to attend everything.

### Communicate Calendar Updates

When you make significant changes to the calendar, let members know through another channel (email, group chat) rather than assuming everyone will notice the calendar update. This is especially important for:

- Cancellations
- Major time changes
- Location changes
- Adding urgent/new events

A quick "Heads up: Tuesday practice is cancelled. Check the calendar for details" saves confusion and ensures the message gets through.

## Advanced Calendar Strategies

Once your basic calendar is running, consider these advanced approaches.

### Color Coding (if available)

If your implementation supports color-coded events, use colors to categorize event types:

- Blue for regular practices
- Green for optional events
- Red for performances/competitions
- Yellow for meetings
- Purple for social events

Visual coding lets members quickly scan the calendar and understand what's coming up.

### Multi-Calendar View

For larger clubs with sub-groups, consider whether your calendar should show everyone's events or just main club activities. Adjust calendar permissions if different groups need different calendar views.

### Integration with External Calendars

Many members want to sync the club calendar with their personal calendars (Google Calendar, Apple Calendar, etc.). If Horenso SPACE provides calendar export or subscription features, show members how to use them. This helps members see club events alongside their personal commitments.

### Attendance Tracking

As members submit absence reports for calendar events, you can see patterns:

- Events with consistently high absences might be poorly scheduled
- Sudden spikes in absences might indicate conflicts with school events
- Low absence rates validate your scheduling decisions

Use this data to improve future scheduling.

## Handling Special Situations

### Cancellations

When you need to cancel an event:

1. Edit the event title to include "CANCELLED" at the start
2. Add a description explaining why (optional but considerate)
3. Update members via another communication channel
4. Consider whether to delete the event or leave it visible as cancelled

Leaving cancelled events visible provides a record that something was planned, which can be useful for tracking why certain weeks were lighter on activity.

### Emergency Schedule Changes

For last-minute changes:

1. Update the calendar immediately
2. Send an urgent message through every communication channel you have (email, group chat, social media)
3. Expect some members won't get the message in time
4. Add a note in the event description about when the change was made

Emergency changes are stressful for everyone. Minimize them when possible, but handle them transparently when necessary.

### Multi-Day Events

For events spanning multiple days (competitions, performances, tours):

- Create separate events for each day, or
- Create one event with a start date and end date spanning the full period

Consider what makes sense for your absence tracking. If members might miss Day 1 but attend Day 2, separate events work better. If the event is all-or-nothing, one multi-day event is cleaner.
