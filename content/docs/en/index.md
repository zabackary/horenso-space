# Welcome

This is the help center for Horenso SPACE. Start here to learn the basics.

- Create a club and invite members
- Submit absence reports
- Review schedules and calendars

# Pricing model

Horenso SPACE is offered on a software-as-a-service model funded entirely by
donations. It is completely open source and can be self-hosted, but by supporting
us financially, you ensure that I can continue to maintain this product in the future.
